pyscal3
=======

.. image:: https://img.shields.io/pypi/v/pyscal3.svg
    :target: https://pypi.org/project/pyscal3/
    :alt: PyPI

.. image:: https://joss.theoj.org/papers/168eca482155601dc517523899527a4e/status.svg
   :target: https://joss.theoj.org/papers/168eca482155601dc517523899527a4e
   :alt: JOSS

**pyscal3** is a Python library for computing local atomic structural
descriptors from atomistic simulation data. It provides a functional,
ASE-first API backed by a fast C++/pybind11 core.

See the `Jupyter Book documentation <https://pyscal3.readthedocs.io>`_
for the full guide, examples, and API reference.
